# 🎮 Dashboard de Vendas — Xbox Game Pass

> **Transformando dados em informações visuais para facilitar a análise de vendas.**

Projeto desenvolvido em **Microsoft Excel** com o objetivo de organizar, analisar e visualizar dados relacionados às vendas de assinaturas do Xbox Game Pass.

O projeto foi desenvolvido como parte de um desafio de **análise e visualização de dados**, buscando transformar dados brutos em informações visuais claras e úteis para apoiar a análise do desempenho de vendas.

---

##  Sobre o projeto

O objetivo deste desafio é criar um **dashboard de vendas**, utilizando o Excel para transformar uma base de dados em uma interface visual que facilite a interpretação das informações.

A proposta é utilizar recursos de organização, análise e visualização de dados para apresentar informações de maneira mais clara, permitindo explorar diferentes recortes por meio de filtros e indicadores.

O dashboard busca transformar uma base de dados em uma ferramenta visual e interativa para análise de informações relacionadas às assinaturas do Xbox Game Pass.

---

## 📊 Objetivo

Transformar dados brutos em informações visuais claras e úteis, permitindo uma análise mais eficiente do desempenho das vendas e apoiando a tomada de decisões baseada em dados.

---

- Filtros para exploração das informações;

- Indicadores de desempenho;
- Interatividade por meio dos filtros disponíveis.

## Informações apresentadas

Entre as informações apresentadas no dashboard estão indicadores relacionados às assinaturas de:

- EA Play Season Pass;
- Minecraft Season Pass;
- Xbox Game Pass.

O dashboard também apresenta uma visualização gráfica relacionada às assinaturas do Xbox Game Pass.

---

## Filtros

O dashboard possui filtros que permitem explorar diferentes recortes das informações disponíveis.

Entre os filtros apresentados está a segmentação por período de assinatura:

- Annual;
- Monthly;
- Quarterly.

A utilização dos filtros permite analisar os dados de diferentes maneiras e observar como os indicadores apresentados no dashboard podem ser explorados de acordo com a seleção realizada.

## Diferenciais do projeto

A proposta não foi apenas apresentar os dados em uma tabela, mas transformar a base em uma interface visual que facilite a interpretação das informações.

O dashboard busca:

- Reduzir a necessidade de análise manual da base;
- Destacar informações relevantes;
- Facilitar a comparação dos dados;
- Permitir diferentes filtros de análise;
- Centralizar as informações em uma única interface;
- Tornar os dados mais acessíveis visualmente.
